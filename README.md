Controls:    
[ Click ] Look around  
[ ESC ] Release mouse  
[ WASD ] Move  
[ C ] Sit in chair  
[ E ] Pick up / drop gun  
[ T ] Toggle TV  
[ L ] Toggle lamp  

What's Special: Different toggles, custom texture on TV Screen mesh, collision checks, a lot of glb files    

Lighting I used:  Hemisphere, Point, Directional
